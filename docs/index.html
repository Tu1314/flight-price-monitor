快速开始

5 分钟完成部署

无需服务器，GitHub Actions 免费执行

1

Fork 仓库

点击右上角 Fork，复制到你自己的 GitHub 账号

2

配置行程

修改 config.example.yaml，填入出发/到达城市和日期

3

填入 SendKey（可选）

在 Settings → Secrets 里加入 SERVERCHAN_SEND_KEY，开启微信提醒

4

手动触发一次

进入 Actions 标签，手动运行 Workflow，验证抓取结果

5

等待降价通知

此后每天自动运行 4 轮，降价时微信收到提醒
